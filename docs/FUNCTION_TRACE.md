# 可选函数级插桩

时间检测页勾选“函数级插桩辅助分析”后，仍首先对原始动态库做正式计时，再独立构建诊断库。未勾选则不构建、不调用诊断库。修改的是诊断副本，原始源码和库不变。

当前范围：mlkem-native SCU 源码家族及已适配构建配置的接入版本；不是任意源码或任意二进制自动插桩。先重构源码并要求与选择的原始库 SHA-256 完全一致，不对应则明确拒绝插桩，同时保留原始库检测结果。

八个阶段：前七个通用阶段为私钥结构检查、内部解密、派生重加密材料、重加密、完整输入比较、拒绝材料派生和最终结果选择；第八个观察点根据所选案例自动放置在基线比较、比较提前结束、条件失败路径、数据相关循环、数据相关访存、条件分支或运行期除法位置。只在实际代码两侧加时钟探针，不替换运算、不统一分支、不更改返回值。分支没有执行对应调用时记零，而不是声称函数耗时为零。

诊断库须通过100次完整流程自测及当前参数集145项公开ACVP向量。采集使用C CLOCK_MONOTONIC_RAW、固定CPU、2000对预热、共同64字节对齐输入地址。随机选择输入样本、类别先后及原始/诊断库调用先后；复制、探针复位和读出在整体计时区间之外。全部原始观测保留。

每轮同时提供A/A同输入诊断对照。阶段差异使用顺序平衡配对统计，八阶段采用0.05/8显著性阈值；显示的95%区间为逐项区间。阶段显著性仅提供候选位置，不作因果或常数时间证明，须结合A/A对照、原始库整体计时、源码及二进制证据。探针会改变代码布局和缓存行为，差异可能受扰动。

开销分别统计正常和变化输入的原始/诊断库均值、p50、p95及均值净开销百分比，且保留配对统计和原始CSV。净变化包含探针、重编译后的代码布局和缓存效应，可能为负，不能声称探针本身加速了程序。另测1000组空探针（八阶段共16个调用）的参考成本并保存CSV；不从实际阶段时长中事后扣除。阶段时长包括时钟探针成本，不能当作无插桩原始函数的真实耗时。

报告不输出输入材料、共享结果、验证布尔值或内部中间状态。计时材料只使用本软件生成的专用实验样本；临时二进制输入文件权限0600，并在完成或异常后删除。证据包包含原始计时CSV、摘要、构建选项、统计及插桩源码，便于复核。
