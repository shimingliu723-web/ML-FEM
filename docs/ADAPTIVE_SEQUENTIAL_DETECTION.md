# 环境感知的自适应序贯检测

## 改进对象

软件原有固定检测方法对每个目标执行10000对输入、3个独立轮次，并为每轮执行同规模A/A对照。该方法口径清楚，但无论差异是否明显都消耗相同样本预算，也不能根据环境抖动调整初始规模。

## 方法

自适应模块不修改计时器、样本定义或统计检验，只增加独立的序贯证据策略：

1. 运行既有环境自检，根据固定工作量探针的p95/median选择预先声明的采样日程。
2. 每个阶段使用新的随机种子，同时采集分类输入和A/A同输入对照。
3. 每阶段计算配对均值差、95%置信区间、统计显著性、检验一致性、方向和实际意义。
4. 连续两个独立阶段显著、检验一致、方向一致、达到实际意义阈值且A/A对照无系统偏移时，提前形成稳定差异结论。
5. 最近三个阶段均不显著且检验一致时，形成“未观察到稳定差异”的有限结论。
6. 证据冲突时继续增加样本；达到最大预算仍不一致则输出“证据不足”，不强行二分。
7. 前后环境检查、核心迁移或A/A系统偏移不通过时，结果降为探索性证据。

服务器当前环境采用1000、3000、10000对的三阶段日程。固定方法的参照预算为30000对。两种方法都执行同规模A/A对照，因此样本节省率按分类配对数计算。

## 软件接入

模块位于 `backend/adaptive_detection.py`，测量仍由 `backend/software_service.py` 的既有 `measure` 函数完成。桌面软件“时间检测”页面保留固定检测按钮，并增加“运行自适应序贯检测”、创新检测轨迹和自适应证据图，不改变定位、修复和报告模块的数据结构。

每次报告保存环境前后检查、样本清单摘要、阶段日程、随机种子、原始CSV路径、阶段判定、停止原因、证据等级、固定预算和节省率。未观察到差异不被解释为绝对常数时间证明。

## 可复现实验

运行：

```bash
.venv/bin/python scripts/accept_adaptive_innovation.py
```

验收实验对7个内置目标分别执行固定方法与自适应方法，比较结论一致率、受控目录判断正确率、正式证据准入和配对样本节省率。若某批次只因既定环境门槛未通过，验收程序最多进行两次独立重测，全部尝试均保留，并选择首个正式批次进入对照。

2026年10月14日服务器实验结果：固定与自适应结论一致率100%，受控目录判断正确率100%，7项均形成正式证据，平均配对样本减少53.33%。
