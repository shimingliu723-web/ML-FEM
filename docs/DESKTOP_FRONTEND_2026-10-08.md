# 桌面可视化前端说明（2026-10-08）

## 1. 为什么增加桌面版

竞赛演示环境可能无法连接校园网或队伍服务器，因此作品不能依赖远程服务器。桌面版前端将现有检测、定位、修复和报告能力包装成本地窗口程序，用户在自己的 Linux/WSL2 环境中即可运行。

## 2. 设计风格

桌面版采用类似往年获奖作品的紧凑后台工具风格：

- 左侧功能导航；
- 右侧信息卡片；
- 表格/日志/结果框同屏展示；
- 一个页面容纳较多关键信息；
- 不需要浏览器、不需要登录、不需要连接队伍服务器。

## 3. 当前页面

| 页面 | 功能 |
|---|---|
| 总览 | 展示当前目标、参数集、项目路径和作品定位 |
| 基础功能 | 运行 ML-KEM 完整流程、自测、公开向量验证 |
| 样本生成 | 调用本地样本生成模块 |
| 时间检测 | 调用高精度计时和正式统计分析 |
| 泄露定位 | 源码定位、二进制定位和源码差异展示 |
| 自动修复 | 生成修复目标并完成修复前后复测 |
| 性能评估 | 输出修复前后运行时间与开销 |
| 报告导出 | 生成或预览报告材料 |

## 4. 运行方式

```bash
python3 -m pip install -r requirements-desktop.txt
./run_desktop.sh
```

或直接运行：

```bash
python3 desktop_app/main.py
```

## 5. 与服务器的关系

服务器只是开发和正式大样本实验环境，不是作品运行的唯一依赖。桌面版直接调用本地 `backend/` 和 `targets/`，可在迁移后的本地工程中运行。

## 6. 数据安全展示策略

桌面版默认不展示完整私钥、完整样本或完整共享结果；基础流程只展示耗时、长度和一致性结论。修复日志只记录目标 ID、文件位置、补丁摘要、统计结果和报告路径。
