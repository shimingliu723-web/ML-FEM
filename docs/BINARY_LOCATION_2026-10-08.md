# 二进制级定位模块说明（2026-10-08）

## 1. 新增能力

平台新增 `backend/binary_audit.py` 和 `/api/binary-locate` 接口，可对当前目标实现的动态库执行反汇编扫描。

当前默认检查函数：

```text
mlkem_dec
```

扫描内容包括：

- 条件跳转指令，例如 `jne` / `je` / `jae` 等；
- 条件移动指令，例如 `cmov*`；
- 条件置位指令，例如 `set*`。

输出内容包括：

- 目标库路径；
- 函数名；
- 指令类别；
- 指令文本；
- 反汇编上下文；
- 日志安全策略。

## 2. 与源码定位的关系

二进制定位不是替代源码定位，而是补上“编译后实际执行了什么”的证据。完整定位流程应为：

```text
源码定位候选位置
  ↓
二进制反汇编检查实际控制流
  ↓
时间检测确认是否有统计差异
  ↓
修复并复测
```

## 3. 小规模验证

在 ML-KEM-512 的 `mlkem_dec` 函数上执行二进制定位，得到：

| 目标 | 条件跳转数 | 条件移动数 | setcc 数 |
|---|---:|---:|---:|
| `variant_early_return` | 7 | 0 | 0 |
| `variant_repaired` | 6 | 0 | 0 |
| `mlkem_native_baseline` | 6 | 0 | 0 |

这说明早退对照版本在编译后二进制层面比修复版/基线多出一条条件控制流候选。该结果需要结合源码定位和计时检测解释，不单独作为泄露结论。

## 4. 日志安全策略

二进制定位只记录库路径、函数名、指令助记符和反汇编片段，不记录私钥、中间状态、完整输入输出或验证内部值。
