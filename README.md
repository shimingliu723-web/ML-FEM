# A1-13 ML-KEM Platform

这是 A1-13 竞赛作品的实验平台仓库。目标是围绕 ML-KEM 解封装实现，完成时间检测、统计分析、定位、防护改造、复测和报告导出。

队员请先看：

```text
docs/TEAM_GUIDE.md
```

## 当前状态

当前是初始平台版本，已经接入：

- ML-KEM-512、ML-KEM-768、ML-KEM-1024
- 基本生成、封装、解封装接口
- 共享值一致性验证
- 公开测试向量验证
- 固定 CPU 核短实验计时检测
- 同一 mlkem-native 实现的正式解封装计时实验：32组等长输入、随机先后顺序、逐次原始数据、配对统计
- 浏览器操作界面

## 正式解封装计时

在 Linux 上执行 `./scripts/build.sh` 后启动平台，选择参数集、CPU 核和配对次数，点击“运行正式检测”。平台会生成32组正常输入及对应的单比特变化输入，预热后在 C 程序内仅围绕 `mlkem_dec` 调用计时。每组配对的先后顺序随机化，原始数据写入 `results/formal_timing/*.csv`，统计摘要写入同名 JSON 文件。

界面给出两类输入的均值、中位数、P95、按采样顺序平衡的配对均值差和95%置信区间。原始样本不做事后剔除。单轮区间是否跨零仅是探索性结果，须检查多轮方向与大小是否一致；没有观察到差异不能证明实现绝对恒定时间。两类样本均为相同长度，核心算法实现与平台基本功能相同。

本实验需要 Linux。正式报告还应记录 CPU 型号、系统版本、编译器及优化级别、频率管理状态和后台负载，并在相同条件下重复多轮测量。
