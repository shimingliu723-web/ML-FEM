# ML-KEM 时间侧信道检测与防护工具桌面版

这是本项目的本地桌面前端。它不是网页，不需要登录，也不需要连接队伍服务器。

## 运行方式

在 Linux/WSL2 项目根目录中运行：

```bash
python3 -m pip install PySide6
python3 desktop_app/main.py
```

桌面版直接调用本地 `backend/` 模块和 `targets/` 目标实现，适合现场演示、小规模实时验证和加载预置结果。

## 当前页面

- 总览
- 基础功能
- 样本生成
- 时间检测
- 泄露定位
- 自动修复
- 性能评估
- 报告导出

## 安全展示策略

桌面版默认不展示完整密钥、完整样本或完整共享结果。基础流程页面只展示耗时、长度和一致性结论。
